# Third-party notices

SWARA AI is built on the work of others. This page credits it and lists the licences of what the project uses directly. It is an honest inventory
taken from the installed packages' own metadata on 10 November 2026; it is **not legal advice or a legal review**. Check licences yourself before you

SWARA AI's own code has no licence file yet. Choose one before you distribute it; until then the default is that all rights are reserved by the owner.

## Gnani.ai (speech models)

Speech recognition uses **Gnani.ai Prisma** and spoken replies use **Gnani.ai Timbre**, through Gnani's public API
(https://docs.gnani.ai) with the user's own API key. Evon is described in [docs/EVON.md](docs/EVON.md) and is **not** used. Gnani, Prisma,
Timbre and Evon are products of Gnani.ai. SWARA AI is not affiliated with or endorsed by Gnani.ai and does not present those models as its own.

## Open Food Facts (product catalogue data)

The public catalogue of 5,325 Indian packaged products is derived from **Open Food Facts** (https://world.openfoodfacts.org/).
Database: **Open Database Licence (ODbL) 1.0**. Individual contents: **Database Contents Licence (DbCL) 1.0**.
Attribution: *Open Food Facts contributors*. The catalogue page shows this attribution, and any copy or derived database must keep it and stay
under the same terms. The data was retrieved through a public republication whose repository is AGPL-3.0; the full provenance, what was changed, and
that licence question are written out in [docs/DATA.md](docs/DATA.md) and `data/sources/`.

Product names and brands in the catalogue and in the evaluation sentences are the property of their owners and appear only to identify products.
No price in the catalogue comes from Open Food Facts; prices in the demo are placeholders.

## Everything else they pull in

- **Frontend, production tree** (what ends up in the browser bundle): 55 packages. 38 MIT, 11 ISC, 4 SIL OFL 1.1 (the font packages), 1 BSD-3-Clause,
  1 with a combined MIT/ISC/BSD-3-Clause expression. No GPL, LGPL, AGPL or unlicensed package.

- Test and build tools (pytest, Vitest, Vite, TypeScript, jsdom, Testing Library, Playwright for the optional browser checks) are used on a
  developer's machine and are not shipped in the built front end.

## Report tooling (release 2.5.0; not part of the app and not installed by `setup.bat`)

`scripts/build_report.py` generates `docs/PROJECT_REPORT.md` (and, with `--files`, the Word and PDF copies) from the saved result files. It is run by a developer on their own machine and its tools are not shipped with the app:

| Tool | Version used | Licence | Use |
|---|---|---|---|
| matplotlib | 3.11.2 | Matplotlib licence (PSF-based, BSD-compatible) | draws the report's figures |
| NumPy | 2.5.3 (system Python used for the report) | BSD-3-Clause | used by matplotlib |
| pandoc | 3.1.3 | GPL-2.0-or-later | converts the report to Word and HTML; run as a separate program, nothing of it is bundled |
| Playwright for Python and Chromium | 1.63.0 | Apache-2.0 (Playwright); Chromium's own licences | prints the HTML report to PDF |

The figures it draws use the brand colours of `frontend/src/styles/tokens.css` and no third-party artwork.

The exact list of every transitive package is in `frontend/package-lock.json` and in `pip freeze` for the environment.
